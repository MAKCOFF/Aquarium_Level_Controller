# Level Controller — Контроллер долива воды (ESP32)

Контроллер автоматического долива воды в аквариум с сампом на базе ESP32. Управляет насосом, клапаном подпитки, контролирует уровень воды и защищает от перелива и пробития мосфетов.

## Возможности

- **Автоматический долив** — насос перекачивает воду из сампа в аквариум при падении уровня
- **Клапан подпитки** — открывает подачу воды из внешней ёмкости при опустошении сампа
- **Защита от перелива** — аварийная остановка при срабатывании датчика перелива
- **Защита от пробитого мосфета** — отключение реле 12В при обнаружении нештатного открытия мосфета
- **Веб-интерфейс** — мониторинг состояния и настройка таймеров через WiFi
- **Сохранение настроек** — таймеры сохраняются в NVS и загружаются при старте

## Состояния системы

### Насос
| Состояние | Описание |
|-----------|----------|
| IDLE | Ожидание, уровень в норме |
| WAITING | Задержка перед запуском насоса |
| PUMPING | Насос работает |
| TURNING_OFF | Задержка перед отключением (докачка) |
| ERROR | Авария (таймаут / перелив / мосфет) |
| DISABLED | Отключено пользователем |

### Клапан
| Состояние | Описание |
|-----------|----------|
| CLOSED | Закрыт |
| OPENING | Задержка перед открытием |
| OPEN | Открыт, наблюдается таймаут |
| CLOSING | Задержка перед закрытием |
| ERROR | Авария (таймаут / мосфет) |

## Защита от пробитого мосфета

Каждые 100 мс проверяется: если сигнал с мосфета LOW (открыт), а команда на насос/клапан не подавалась — мосфет считается пробитым.

При срабатывании:
1. Отключается реле 12В (обесточивает силовую часть)
2. Зажигаются оба красных светодиода (индикация аварии)
3. Зуммер работает 60 секунд
4. Система переходит в STATE_ERROR / VALVE_ERROR

Сброс: кнопка на корпусе или кнопка «Сброс / АВТО» в веб-интерфейсе.

## Веб-интерфейс

После подключения к WiFi ESP32 поднимает HTTP-сервер в локальной сети роутера.

> **Важно:** Веб-страница доступна только в локальной сети роутера, к которому подключена ESP32.

### Как узнать IP-адрес

- **Через админку роутера** — зайти в веб-интерфейс роутера и найти ESP32 в списке подключённых устройств
- **Через USB** — подключить плату к компьютеру, открыть Serial Monitor (`idf.py monitor`) — IP-адрес выводится при подключении к WiFi

> **Важно:** Нельзя включать питание платы без подключённой WiFi-антенны — это может повредить радиочасть ESP32.

### Эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | Веб-страница |
| GET | `/status.json` | JSON со статусом системы |
| POST | `/set_timer` | Установка таймера `{"timer":"имя","value":мс}` |
| GET | `/off` | Сброс в автоматический режим |
| GET | `/disable` | Полное отключение |

### Настраиваемые таймеры

| Таймер | Описание | По умолчанию | Диапазон |
|--------|----------|--------------|----------|
| wait | Задержка запуска насоса | 20 сек | 5–60 сек |
| safety | Защитный таймер насоса | 30 сек | 10–60 сек |
| stop | Докачка после достижения уровня | 5 сек | 1–20 сек |
| buzzer | Длительность зуммера | 60 сек | 10–120 сек |
| valve_delay | Задержка открытия клапана | 5 сек | 1–30 сек |
| valve_timeout | Таймаут работы клапана | 60 сек | 10–600 сек |
| valve_close_delay | Задержка закрытия клапана | 10 сек | 1–20 сек |

## Сборка и прошивка

Разработка и сборка выполнены на **ESP-IDF v5.5.4**.

Требуется [ESP-IDF v5.x](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/get-started/).

```bash
# Настроить целевой чип
idf.py set-target esp32

# Собрать
idf.py build

# Прошить и открыть монитор
idf.py -p /dev/ttyUSB0 flash monitor
```
